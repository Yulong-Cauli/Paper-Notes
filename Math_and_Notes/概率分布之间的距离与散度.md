# 概率分布之间的距离与散度

---

## 一、Total Variation Distance（总变差距离，TVD）

### 1.1 定义

对于两个概率分布 $P$ 和 $Q$，总变差距离定义为所有可测事件 $A$ 上概率差的上确界

$$
\|P - Q\|_{TV} = \sup_{A} |P(A) - Q(A)|
$$

若 $P$ 和 $Q$ 关于某个共同测度存在密度函数 $p(x)$ 和 $q(x)$，则有等价形式

$$
\|P - Q\|_{TV} = \frac{1}{2} \int |p(x) - q(x)| \, dx = \frac{1}{2} \|p - q\|_{L^1}
$$

离散形式，设样本空间为 $\mathcal{X}$，$P(x)$ 和 $Q(x)$ 为概率质量函数
$$
\|P - Q\|_{TV} = \frac{1}{2} \sum_{x \in \mathcal{X}} \left| P(x) - Q(x) \right|
$$

等价地，两个分布的总概率质量都是1，相等。所以 $P$ 比 $Q$ 多出来的质量，必然等于 $Q$ 比 $P$ 多出来的质量

$$
\|P - Q\|_{TV} = \sum_{x \in \mathcal{X}: P(x) > Q(x)} \left( P(x) - Q(x) \right)
$$

---

### 1.2 核心性质

| 性质           | 说明                              |
| :------------- | :-------------------------------- |
| **取值范围**   | $[0, 1]$（对于概率分布）          |
| **对称性**     | $\|P - Q\|_{TV} = \|Q - P\|_{TV}$ |
| **三角不等式** | 满足，是真正的度量                |
| **概率解释**   | 区分 $P$ 与 $Q$ 的最优检验误差    |

### 1.3 直观理解

- TVD 得到的是两个分布**不重叠的概率质量**，量化了两个分布在统计上 “可区分程度” 的极限。
- 值为 $0$，两分布完全相同；值为 $1$，两分布支撑集完全不重叠；（**支撑集**是定义域中排除了零概率点的子集）
- 衡量的是 最优统计检验 能区分两者的程度， 最优检验的最低错误概率 $= \frac{1}{2}\left(1 - \|P - Q\|_{TV}\right)$

## 二、Kullback-Leibler Divergence（KL 散度）

### 2.1 定义

$$
D_{KL}(P \| Q) = \int p(x) \log \frac{p(x)}{q(x)} \, dx
$$

离散形式，约定：当 $P(x) = 0$ 时，该项为 $0$；当 $P(x) > 0$ 且 $Q(x) = 0$ 时，$D_{KL}(P \| Q) = +\infty$。
$$
D_{KL}(P \| Q) = \sum_{x \in \mathcal{X}} P(x) \log \frac{P(x)}{Q(x)}
$$

### 2.2 核心性质

| 性质                 | 说明                                               |
| :------------------- | :------------------------------------------------- |
| **非负性**           | $D_{KL}(P \| Q) \geq 0$，等号当且仅当 $P = Q$      |
| **非对称性**         | $D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$，**不是度量** |
| **无界性**           | 可能为 $+\infty$（当 $Q$ 的支撑集不包含 $P$ 时）   |
| **不满足三角不等式** | 不是度量                                           |

### 2.3 直观理解

- 表示用分布 $Q$ 近似真实分布 $P$ 时，**平均额外需要的编码长度**（信息量）
- 对 $Q$ 的"遗漏"极其敏感：若 $P$ 在某区域有质量而 $Q$ 为 $0$，则 KL 散度为 $+\infty$
- $D_{KL}(P \| Q)$：要求 $Q$ 覆盖 $P$ 的所有模式（mode-covering）
- $D_{KL}(Q \| P)$：要求 $Q$ 逼近 $P$ 的主要模式（mode-seeking）

### 2.4 应用场景

- **变分推断（VI）**：用简单分布 $Q$ 近似复杂后验 $P$
- **VAE**：证据下界（ELBO）中包含 KL 正则项
- **信息论**：信道容量、率失真理论

## 三、Jensen-Shannon Divergence（JS 散度）

### 3.1 定义

设 $M = \frac{P + Q}{2}$ 为两个分布的平均分布，则：

$$
D_{JS}(P \| Q) = \frac{1}{2} D_{KL}\left(P \,\|\, M\right) + \frac{1}{2} D_{KL}\left(Q \,\|\, M\right)
$$

即：

$$
D_{JS}(P \| Q) = \frac{1}{2} D_{KL}\left(P \,\|\, \frac{P+Q}{2}\right) + \frac{1}{2} D_{KL}\left(Q \,\|\, \frac{P+Q}{2}\right)
$$

### 3.2 核心性质

| 性质         | 说明                                                 |
| :----------- | :--------------------------------------------------- |
| **对称性**   | $D_{JS}(P \| Q) = D_{JS}(Q \| P)$                    |
| **有界性**   | $0 \leq D_{JS}(P \| Q) \leq \log 2$（对概率分布）    |
| **有限性**   | 即使支撑集不相交，JS 散度也有限                      |
| **度量版本** | $\sqrt{D_{JS}(P \| Q)}$ 满足三角不等式，是真正的度量 |

### 3.3 直观理解

- 通过对称化 KL 散度，解决了 KL 的不对称和无界问题
- 衡量的是：相比于直接知道 $P$ 或 $Q$ 来自哪一个，通过混合分布 $M$ 带来的平均信息增益

### 3.4 应用场景

- **GAN**：Goodfellow (2014) 原始 GAN 的理论框架基于最小化 JS 散度
- **分布相似度度量**：文本、图像等分布的比较
- **信息几何**

## 四、三者对比

| 特性               | **TVD**      | **KL**                | **JS**           |
| :----------------- | :----------- | :-------------------- | :--------------- |
| **对称性**         | ✓            | ✗                     | ✓                |
| **有界性**         | ✓ $[0,1]$    | ✗ $[0,+\infty]$       | ✓ $[0, \log 2]$  |
| **是度量？**       | ✓            | ✗                     | 开方后是 ✓       |
| **对支撑集敏感度** | 中等         | 极强（可为 $\infty$） | 弱（始终有限）   |
| **概率/信息解释**  | 最优检验误差 | 编码额外代价          | 混合分布信息增益 |

## 五、相互关系

### 5.1 Pinsker 不等式（KL → TVD）

$$
\|P - Q\|_{TV} \leq \sqrt{\frac{1}{2} D_{KL}(P \| Q)}
$$

KL 散度控制 TVD，但反之不成立。

### 5.2 JS → TVD

$$
\|P - Q\|_{TV} \leq \sqrt{2 \cdot D_{JS}(P \| Q)}
$$

### 5.3 JS 与 KL 的关系

$$
D_{JS}(P \| Q) \leq \frac{1}{2} D_{KL}(P \| Q) + \frac{1}{2} D_{KL}(Q \| P)
$$

JS 散度是两个方向 KL 到混合分布的加权平均，**不等于** $D_{KL}(P\|Q)$ 与 $D_{KL}(Q\|P)$ 的简单算术平均。

---

## 六、总结

| 工具    | 核心特点                     | 典型用途                           |
| :------ | :--------------------------- | :--------------------------------- |
| **TVD** | 直观、有界、是度量           | 马尔可夫链收敛、假设检验、差分隐私 |
| **KL**  | 信息论本质、不对称、可能无穷 | 变分推断、VAE、信息论              |
| **JS**  | 对称、有界、源于 KL          | GAN、分布比较、信息几何            |

**一句话**：KL 是信息论的核心但不完美；JS 通过对称化和有界化修正了 KL 的缺陷；TVD 是概率意义上最直观的差异度量。三者通过 Pinsker 不等式等关系相互联系，各有其最适用的场景。
