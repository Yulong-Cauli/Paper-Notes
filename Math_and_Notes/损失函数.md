# 损失函数

## 二分类交叉熵（CE）：

### 定义

标准二分类交叉熵（CE），其中 $p_t$ 是模型对**真实类别**的预测概率，真实是正类：$p_t = p$ ；真实是负类：$p_t = 1-p$。

$$
CE(p_t) = -\log(p_t) \\
CE(p, y) = -[y \log(p) + (1-y)\log(1-p)]
$$

**交叉熵就是让模型对正确类别的预测概率尽可能大，对错误类别尽可能小，且对"自信的错误"惩罚极重。**

假设三分类，真实类别是"猫"：

| 类别 | 真实 y | 预测 A | 预测 B |
| ---- | ------ | ------ | ------ |
| 猫   | 1      | 0.9    | 0.3    |
| 狗   | 0      | 0.05   | 0.3    |
| 鸟   | 0      | 0.05   | 0.4    |

- 预测 A 的损失：$-\log 0.9 \approx 0.105$；预测 B 的损失：$-\log 0.3 \approx 1.204$

预测 A 更自信且正确，损失更小。交叉熵**惩罚"自信的错误"**：如果真实类别预测概率接近0，损失会趋向无穷大。

### 梯度推导（softmax + CE）

设 $z$ 是 logits，$\hat{y}_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$，损失 $L = -\log \hat{y}_c$。

对 logits 求导：

$$
\frac{\partial L}{\partial z_i} = \hat{y}_i - y_i
$$

这个形式非常优雅：**预测值减真实值**，误差越大梯度越大，且不会饱和。

### PyTorch 实现

```python
import torch
import torch.nn as nn

# ----- 二分类 -----
criterion = nn.BCELoss()          # 需要先过 sigmoid
# 或更推荐（数值更稳定）：
criterion = nn.BCEWithLogitsLoss()  # 内部含 sigmoid

pred = torch.tensor([0.9, 0.1, 0.7])
target = torch.tensor([1.0, 0.0, 1.0]) 
# 二分类里 target 必须是 float 类型（0.0 或 1.0）
# 1.0是正类，0.0是负类
loss = criterion(pred, target)

# ----- 多分类 -----
criterion = nn.CrossEntropyLoss()  
# nn.CrossEntropyLoss = LogSoftmax + NLLLoss，所以不要手动再 softmax。

logits = torch.tensor([[2.0, 1.0, 0.1],
                       [0.5, 2.5, 0.3]])
target = torch.tensor([0, 1])
# 多分类里 target 必须是 int64
# 表示类别索引
loss = criterion(logits, target)
```

## Focal Loss

### 定义

**Focal Loss = 交叉熵 × 类别权重 × 难度调制因子**。
$$
FL(p_t) = -\alpha_t (1-p_t)^\gamma \log(p_t) \\
FL(p, y) = -\alpha y (1-p)^\gamma \log(p) - (1-\alpha)(1-y) p^\gamma \log(1-p)
$$

相比 CE，调制因子 和 类别权重：

| **调制因子**，降低简单样本的权重 | $(1-p_t)^\gamma$ |
| -------------------------------- | ------------------ |
| **类别权重**，平衡正负样本 | $\alpha_t$ |

其中

- $\gamma \geq 0$ 是**聚焦参数**，通常取 2
- $\alpha_t$ 是类别平衡权重，通常正类取 0.25，负类取 0.75

### 调制因子 $(1-p_t)^\gamma$ 的作用

看它的行为：

- **样本被预测得很好**（$p_t \to 1$）：$(1-p_t)^\gamma \to 0$，loss 被大幅压低
- **样本被预测得很差**（$p_t \to 0$）：$(1-p_t)^\gamma \to 1$，loss 几乎不受影响

举例，取 $\gamma = 2$：

| $p_t$     | CE loss | $(1-p_t)^2$ | FL loss |
| ----------- | ------- | ------------- | ------- |
| 0.9（简单） | 0.105   | 0.01          | 0.001   |
| 0.5（中等） | 0.693   | 0.25          | 0.173   |
| 0.1（困难） | 2.303   | 0.81          | 1.865   |

这样梯度就自动集中到难样本上。

### $\alpha_t$ 的作用

$\alpha_t$ 是一个静态的类别权重，用来处理**正负样本数量悬殊**的问题：

- 正样本少 → 给正样本更大权重（如 $\alpha = 0.25$ 是给正类的，负类为 0.75）
- 注意：在 RetinaNet 中，$\alpha=0.25$ 配合 $\gamma=2$ 效果最好，虽然正类权重看起来更小，但因为负类数量极多，整体仍然平衡

实际上，$\alpha_t$ 和 $(1-p_t)^\gamma$ 是互补的：前者处理**数量不平衡**，后者处理**难度不平衡**。

### PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0, reduction='mean'):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction

    def forward(self, logits, targets):
        # logits: [N, C], targets: [N]
        ce_loss = F.cross_entropy(logits, targets, reduction='none')
        pt = torch.exp(-ce_loss)  # p_t
        focal_loss = self.alpha * (1 - pt) ** self.gamma * ce_loss

        if self.reduction == 'mean':
            return focal_loss.mean()
        elif self.reduction == 'sum':
            return focal_loss.sum()
        else:
            return focal_loss
```

注意：这里用 `exp(-ce_loss)` 得到 $p_t$，是因为 `ce_loss = -log(p_t)`。
