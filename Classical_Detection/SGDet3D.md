# SGDet3D ：面向4D雷达与相机融合的语义与几何融合3D目标检测

**出处期刊：** IEEE Robotics and Automation Letters (RA-L) 2025

**是否开源：** https://github.com/shawnnnkb/SGDet3D

**关键词：** 4D毫米波雷达-相机融合、几何深度补全、语义雷达PillarNet、面向对象的交叉注意力、特征解耦

------

## 1. 概述

SGDet3D 旨在解决现有 4D 雷达与相机融合模型中单模态信息利用不充分以及缺乏深层跨模态交互的问题。

- **双分支融合模块 (Dual-Branch Fusion Module)**：在早期特征提取阶段，通过几何深度补全 (GDC) 利用雷达物理先验修正相机深度，通过语义雷达 PillarNet (SRP) 利用图像语义丰富雷达特征，实现显式的模态间优劣势互补。
- **面向对象的注意力模块 (Object-Oriented Attention Module)**：构建具有强空间辨识度的 3D 特征空间，利用定位感知交叉注意力 (LACA) 实现 BEV 查询与目标级图像特征的深层交互聚合。
- **性能**：在 VoD 和 TJ4DRadSet 数据集上达到 SOTA 水平。

------

## 2. 双分支融合模块

该模块分别处理异构数据的单向增强，最终将双分支特征在统一的 BEV 空间对齐并融合生成 RC-BEV。

### 2.1 几何深度补全 (GDC)

利用邻域交叉注意力 (NCA) 算子，将稀疏雷达深度扩散至图像特征，输出密集离散深度概率分布 $D \in \mathbb{R}^{H \times W \times D_{bin}}$。结合图像上下文语义特征 $C$，通过张量外积与体素池化生成几何感知的图像 BEV 特征：

$$F_C^{BEV} = \text{VoxelPooling}(D \otimes C)$$

### 2.2 语义雷达 PillarNet (SRP)

通过构建 3D 虚拟点集并在透视图中检索语义特征。引入 GDC 生成的深度概率 $D$ 作为标量权重 $d^i$，对投影射线上的虚拟点特征进行深度去歧义与重加权。加权后的特征集 $\hat{P}$ 经 Pillar Collapse 高度维压缩后与初始雷达特征 $R$ 拼接：

$$F_R^{BEV} = \text{conv}(\text{concat}(R, \text{MLP}(\hat{P})))$$

------

## 3. 面向对象的注意力模块

### 3.1 3D 特征空间构建

使用透视图前景掩码 $M$ 进行像素定向 (Pixel-Ort)，使用深度分布 $D$ 进行深度定向 (Depth-Ort)。其代数形式排除了无效背景域并提供了 3D 物理先验：

$$\hat{F}^{3D} = \hat{M} \odot (D \otimes F^{2D})$$

### 3.2 定位感知交叉注意力 (LACA)

以融合得到的 RC-BEV 作为初始 3D Queries，在定向后的 3D 特征空间 $\hat{F}^{3D}$ (Keys/Values) 中执行 3D 可变形注意力聚合。对于 3D 参考点 $q$：

$$LACA(Q_q, \hat{F}^{3D}, q) = \sum_{n=1}^N A_n W \cdot \phi(\hat{F}^{3D}, \mathcal{P}(q) + \Delta q)$$

------

## 4. 联合多任务损失函数

模型采用多任务架构，深度损失经过前景焦点加权（系数 $\beta$），分类掩码损失用于监督像素定向算子的先验：

$$\mathcal{L}_{total} = \mathcal{L}_{det} + \lambda_{1}\mathcal{L}_{depth} + \lambda_{2}\mathcal{L}_{seg}$$

其中 $\mathcal{L}_{depth} = M \odot KL(D, D_{gt})$，真值 $D_{gt}$ 经过 One-Hot 离散化编码处理。

------

## 5. 消融实验与分析

### 5.1 核心组件消融 (VoD 数据集)

| **配置** | **SRP** | **GDC** | **LACA** | **mAP<sub>EAA</sub>** | **mAP<sub>DC</sub>** |
| -------- | ------- | ------- | -------- | --------------------- | -------------------- |
| Baseline |         |         |          | 50.44                 | 69.76                |
| + SRP    | ✓       |         |          | 56.11                 | 73.06                |
| + GDC    | ✓       | ✓       |          | 58.27                 | 75.80                |
| 完整模型 | ✓       | ✓       | ✓        | **59.49**             | **77.11**            |

**分析**：特征解耦的 SRP 和 GDC 显著提升了检测基线，LACA 模块的深层交互进一步利用了双分支提供的优质 Token 空间，实现了性能最大化。

### 5.2 LACA 内部定向机制消融

| **定向机制**                    | **mAP<sub>EAA</sub>** | **mAP<sub>DC</sub>** |
| ------------------------------- | --------------------- | -------------------- |
| Baseline (无定向)               | 55.79                 | 73.19                |
| Depth-Ort (无 GDC 增强)         | 54.29                 | 73.25                |
| Depth-Ort + GDC                 | 58.19                 | 75.28                |
| **Pixel-Ort + Depth-Ort + GDC** | **58.35**             | **75.57**            |

**分析**：在缺乏物理先验（无 GDC）时强行执行深度定向映射，劣质的深度概率会污染 3D Key/Value 特征空间，导致注意力采样坍塌。高质量的 GDC 是 3D 特征空间构建的必要前置条件。

### 5.3 深度监督源分析

| **深度监督标签 (Depth Label)** | **mAP<sub>EAA</sub>** | **mAP<sub>DC</sub>** |
| ------------------------------ | --------------------- | -------------------- |
| None                           | 56.95                 | 74.12                |
| Radar Point Cloud              | 58.75                 | 74.03                |
| **LiDAR Point Cloud**          | **59.49**             | **77.11**            |

**分析**：仅使用稀疏的雷达点云监督即可达到 58.75 的 mAP，验证了该几何感知范式的可行性。引入高密度 LiDAR 真值监督可进一步解锁深度估计算子的性能上限。
