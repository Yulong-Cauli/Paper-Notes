# SparseOcc: Fully Sparse 3D Occupancy Prediction

**出处会议：** ECCV 2024
**是否开源：** https://github.com/MCG-NJU/SparseOcc
**关键词：** 全稀疏架构、占据预测、掩码引导稀疏采样、RayIoU、时序建模

------

## 1. 概述

解决 3D 占据预测中稠密代价卷（Dense Cost Volume）带来的 $O(L^3)$ 计算冗余问题。

SparseOcc 利用场景的固有稀疏性，跳过稠密特征构建，直接在稀疏空间进行几何重建与语义预测。

$$
\text{Images} \rightarrow \text{Sparse Voxel Decoder} \rightarrow \text{Mask Transformer} \rightarrow \text{RayIoU Evaluation}
$$

彻底摒弃稠密的张量表示，整个网络的数据流从头到尾仅维护一个**稀疏的非空 3D 坐标点集 (Sparse Token List)**。所有特征提取、语义分割均直接在离散的三维坐标点上执行。



------

## 2. 核心技术实现细节 (How)

### 2.1 稀疏体素解码器 (Sparse Voxel Decoder)

**技术目标**：在不构建全局张量的前提下，找出 3D 空间中存在物体的几何表面。

**算子逻辑**：基于从粗到细（Coarse-to-fine）的层次化生成与空间剪枝。

1. **空间初始化 (Layer 1)**：在 3D 空间生成极低分辨率的均匀体素网格查询 $Q_1 \in \mathbb{R}^{N_1 \times C}$。

2. **自适应特征混合 (Adaptive Mixing)**：取代传统的 3D 卷积。对于每个活跃体素查询 $q_i$ 及其物理坐标 $P_i$：

   - 通过线性层预测 $K$ 个 3D 局部空间偏移量 $\Delta P_{ik}$。

   - 利用相机内外参矩阵将偏移后的 3D 点投影至多视图 2D 图像平面：

     $$x_{v,k} = \mathbf{K}_v [\mathbf{R}_v | \mathbf{t}_v] (P_i + \Delta P_{ik})$$

   - 在 2D 特征图上执行双线性插值采样，并通过 $q_i$ 生成的动态权重张量执行矩阵乘法聚合，完成特征写入。

3. **二分类剪枝 (Pruning)**：通过 MLP 预测当前尺度下 $N_{active}$ 个体素的占据得分 $s \in [0, 1]$。执行硬过滤，仅在内存中保留得分 $s > \tau$ 的 Token。

4. **空间上采样**：将保留下来的物理体素在 3D 坐标系中 8 等分（各轴分辨率 $\times 2$）。子体素继承父级特征，作为下一层的初始查询 $Q_{l+1}$。

5. **递归执行**：重复上述过程 $L=3$ 次。最终输出的 Token 列表仅覆盖高分辨率下的物理表面，计算复杂度从 $O(L^3)$ 降至 $O(N_{active})$。

### 2.2 掩码 Transformer (Mask Transformer)

**技术目标**：在解码器提供的几何表面点集上，预测语义类别和实例。

**传统方法痛点**：标准 Mask2Former 的 Object Query 需要与所有 3D 体素进行全局交叉注意力计算，时间复杂度为 $O(N_{query} \cdot M_{voxel})$。在 3D 高分辨率下，体素基数过大导致算子无法执行。

**解决路径：掩码引导稀疏采样 (Mask-guided Sparse Sampling, MGSS)**

1. **生成初始掩码分布**：查询向量 $Q_m$ 与活跃体素特征计算点积，通过 Softmax 得到该实例在 3D 空间的初步概率分布张量 $M_i$。

2. **坐标点采样**：抛弃全局加权求和，将 $M_i$ 作为离散概率密度函数，在 3D 物理空间中**随机采样**固定数量的 $N_p$ 个点（如 96 个点）。

3. **投影与更新**：将这 $N_p$ 个采样点的 3D 坐标投影回 2D 图像获取特征，并更新该实例的 Object Query。

   **本质差异**：将 Cross-Attention 的稠密矩阵乘法，降维成基于先验掩码分布的稀疏索引采样，复杂度被严格绑定为 $O(N_{query} \cdot N_p)$。

### 2.3 射线评估指标 (RayIoU)

**技术目标**：解决传统 mIoU 对深度轴惩罚不一致的问题。

**计算流程**：

1. 模拟物理传感器的扫描行为，从自车相机中心向 3D 预测空间和真值空间投射高密度射线 $r$。

2. 在每条射线路径上，执行射线求交算法，记录其**首次**命中非空体素的类别 $c$ 和深度距离 $d$。

3. **真正例 (TP) 判定算子**：一条射线被判为正确需同时满足两项布尔逻辑：

   - 语义类别绝对相等：$c_{pred} == c_{gt}$。

   - 深度 L1 误差满足阈值：$|d_{pred} - d_{gt}| < \tau$（$\tau$ 设为 1m, 2m, 4m）。

     **指标影响**：彻底封堵了模型通过“将表面预测得很厚”来提高体积重叠概率的作弊路径。只要表面首次接触点的深度位置错误，无论物体内部体积多大，该射线均判定为假正例 (FP)。

## 3. 实验数据与因果关联

**测试环境**：Occ3D-nuScenes 数据集，Tesla A100 (fp32)。

| **方法架构**  | **3D 表示范式**            | **时序输入** | **RayIoU** | **FPS (推理速度)** |
| ------------- | -------------------------- | ------------ | ---------- | ------------------ |
| BEVFormer     | 稠密 (Dense Cost Volume)   | 4帧          | 32.2       | 2.3                |
| FB-Occ        | 稠密 (Dense Cost Volume)   | 16帧         | 33.7       | 5.2                |
| **SparseOcc** | **全稀疏 (Sparse Tokens)** | **7帧**      | **34.0**   | **17.3**           |

**底层逻辑支撑**：

1. **FPS 突破的数学解释**：解码器在低分辨率阶段物理抹除了 $>90\%$ 的背景空间节点，后续所有算子（自注意力、投影、MLP）的矩阵维度仅取决于 $N_{active}$。去除了体积依赖后，FPS 实现量级跃升。
2. **长时序建模的资源释放**：全稀疏架构极大地降低了单帧特征的显存占用。通过坐标系变换矩阵 $\mathbf{T}_{curr \to prev}$ 将当前 3D 坐标直接映射到历史多帧图像上提取特征，系统能以极低代价处理 15 帧输入（RayIoU 达 35.1），补全了单帧图像中被遮挡的截断面。
