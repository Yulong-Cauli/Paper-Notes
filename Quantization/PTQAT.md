# PTQAT: A Hybrid Parameter-Efficient Quantization Algorithm for 3D Perception Tasks

**出处会议：** ICCV 2025  
**是否开源：** 暂无  
**关键词：** 3D感知网络、混合量化、PTQ+QAT、误差传播、自动驾驶部署

---

## 1. 概述

在 3D 感知任务（目标检测、BEV分割、占据预测）的落地中，传统量化面临两难：
*   **PTQ（训练后量化）**：速度快，但在极低比特（如 4-bit）下精度崩塌。
*   **QAT（量化感知训练）**：精度高，但需要微调所有权重，显存占用极大，训练时间漫长。

**PTQAT** 提出了一种高效的**混合量化**框架：挑选部分关键网络层进行 QAT 微调，剩下的层保持 PTQ 量化（冻结近 50% 的层）。
**核心反直觉发现**：应该去微调那些**“量化前后输出误差小”**的层（阻断误差传播），而不是去微调“误差大”的层（试图修复误差源头）。最终在减少一半训练参数的情况下，实现了超越全参数 QAT 的精度。

---

## 2. 方法

PTQAT 的核心思路是：**量化误差最关键的影响在于它的传播路径，而不是它的发源地。**

### 2.1 PTQ 预检查 (PTQ Pre-Check)

首先对整个模型进行一次基础的均匀对称量化（PTQ），以此来评估量化对每一层初始输出的破坏程度。
对于某一层的全精度输入 $A$ 和权重 $W$：

1.  **全精度输出**：$X = F(W, A)$
2.  **量化后输出**：$X_Q = F(Q(W), A)$

使用 **均方误差 (MSE)** 来衡量该层的初始量化偏差：

$$
Dis(\mathbb{X}_Q, \mathbb{X}) = MSE(\mathbb{X}_Q, \mathbb{X})
$$

### 2.2 QAT 局部微调 (QAT Fine-Tune)

通过一个超参数阈值 $\theta$ 来决定哪些层参与 QAT（解冻权重），哪些层保持纯 PTQ（冻结权重）。

$$
\text{Fine-tune} = \begin{cases} 
\text{True,} & \text{if } Dis(\mathbb{X}_Q, \mathbb{X}) < \theta \\ 
\text{False,} & \text{otherwise} 
\end{cases}
$$

**为什么挑选误差小 ($Dis < \theta$) 的层进行微调？**
*   **传统直觉的陷阱**：认为误差大的层是罪魁祸首，去修补它。但实际上，这会导致残余误差在未微调的下游网络中如水波般扩散，导致特征图发生全局崩溃。
*   **PTQAT 的逻辑（误差海绵）**：误差小的层之所以误差小，是因为它们吃的是“完美的 FP32 输入”。当上游误差传导下来时，这些层会面临严重的输入分布偏移（Distributional shifts）。如果不微调它们，它们毫无抵抗力。因此，**主动微调这些低误差层，让它们学会“消化”和“补偿”上游传导来的畸变**，从而把误差圈禁在局部。

### 2.3 部署友好限制 (Deploy Friendly Constraint)

为了保证训练出的模型能在真实车端硬件上无缝运行：
*   **坚决不使用花哨的自定义算子**。全程采用最基础、硬件最喜欢的**均匀对称量化 (Uniform Symmetric Quantization)**。
*   反向传播时使用标准的 **直通估计器 (STE, Straight-Through Estimator)** 处理舍入函数的不可导问题，同时将缩放因子 $s$ 设为可训练参数。

## 3. 实验结果与深度分析

### 3.1 3D 目标检测主线对比 (Table 1)
在 nuScenes 数据集上，基于单卡 A100，测试极低比特 **W4（4-bit 权重量化）**。

| **Model**     | **Method** | **Param (可训练参数)** | **Cost (耗时)** | **mAP**  | **NDS**  |
| :------------ | :--------- | :--------------------- | :-------------- | :------- | :------- |
| **SparseBEV** | FP32 基准  | -                      | -               | 45.4     | 55.5     |
|               | PTQ Only   | 0                      | 0               | 30.5     | 42.9     |
|               | 全参数 QAT | 44.6M                  | 15658s          | 43.6     | 54.3     |
|               | **PTQAT**  | **32.7M** (-26%)       | **13849s**      | **44.6** | **55.2** |
| **BEVFormer** | FP32 基准  | -                      | -               | 41.6     | 51.7     |
|               | PTQ Only   | 0                      | 0               | 23.2     | 37.6     |
|               | 全参数 QAT | 69.0M                  | 47268s          | 38.0     | 48.8     |
|               | **PTQAT**  | **18.7M** (-73%)       | **44493s**      | **38.6** | **49.1** |

**分析**：纯 PTQ 会导致 3D 模型精度雪崩。PTQAT 以**极少的可训练参数**（BEVFormer 甚至只训了四分之一的参数），实现了**反超全参数 QAT** 的精度。证明了“挑对关键层”比“全盘盲目微调”更有效。

### 3.2 灵魂消融实验：验证反直觉度量 (Table 6)
控制所有方法微调相同数量的网络层，验证挑选层的指标，基座为 BEVDepth4D。

| **挑选层的依据 (Method)**   | **mAP**  | **NDS**  | **评价**                       |
| :-------------------------- | :------- | :------- | :----------------------------- |
| Huber Loss                  | 39.6     | 51.4     | 对大误差不敏感，效果一般       |
| Cosine (余弦相似度)         | 39.5     | 51.3     | 只看方向不看幅度，无法找误差   |
| Random (随机挑选)           | 39.3     | 51.3     | 纯盲盒瞎选                     |
| **MSE-Opposite (挑误差大)** | 39.3     | **51.1** | **违背规律，连随机选都不如**   |
| **MSE (PTQAT 挑误差小)**    | **40.0** | **51.6** | **精准切断传播路径，断崖领先** |

**分析**：本表是全文的逻辑核心。`MSE-Opposite`（即传统认知中“哪里误差大修哪里”）表现垫底，彻底证明了**处理量化误差的核心在于切断传播链，而非死磕发源地**。

### 3.3 真实硬件落地加速 (Table 5)
在 NVIDIA TensorRT 上部署量化后的 BEVDepth4D 模型（采用工业标准的 W8A8）。

| **部署方式**          | **mAP**  | **NDS**  | **FPS** | **GPU 显存** |
| :-------------------- | :------- | :------- | :------ | :----------- |
| FP16 (原版)           | 40.8     | 52.2     | 18      | 860M         |
| NVIDIA PTQ (官方默认) | 32.4     | 44.1     | **35**  | 607M         |
| **PTQAT (W8A8)**      | **38.0** | **50.3** | 31      | **503M**     |

**分析**：官方一键 PTQ 虽然快，但精度暴跌（NDS 掉到 44.1），不可用。PTQAT 产出的模型可以无缝编译为标准的 TensorRT 引擎，在精度几乎持平 FP16 的情况下，**帧率接近翻倍，显存节省超 40%**。

## 4. 总结笔记

1.  **理论突破**：打破了“修补误差源头”的量化直觉，提出“量化误差最关键的影响在于其传播路径”，将下游网络层转变为“误差海绵”。
2.  **效率革命**：通过 MSE 预检查，精准冻结一半以上的网络层，用 PTQ 的开销换取了超越 QAT 的性能。
3.  **工程闭环**：没有沉溺于学术界花哨但不落地的自定义算子，坚持均匀对称量化，打通了从 PyTorch 训练到 NVIDIA TensorRT 部署的完整链路，是自动驾驶模型落地的极佳参考。
